Yeu cau tai cau truc route/domain PinkLove
=========================================

Muc tieu
--------
- To chuc lai routing/domain cua ung dung PinkLove thanh 2 site surface ro rang:
  - `admin-site`: admin backoffice, chay theo domain/subdomain admin cau hinh bang env.
  - `user-site`: public website + customer portal + provider portal, chay theo public domain.
- API dung chung tiep tuc nam trong `web/src/app/api`.
- Domain admin tam thoi la `system.pinklove.vn`, cau hinh bang env de sau nay co the doi.
- Customer va Provider portal nam chung public domain de flow auth, checkout, payment, affiliate, email link va SEO lien mach.

Boi canh du an
--------------
- Next.js app nam trong thu muc `web/`.
- Proxy layer hien co nam tai `web/src/proxy.ts`.
- Route constants nam tai `web/src/lib/routes.ts`.
- API routes nam tai `web/src/app/api`.

Bien moi truong
---------------

Local:

```env
PUBLIC_DOMAINS=localhost:3000
ADMIN_DOMAINS=system.localhost:3000
```

Production:

```env
PUBLIC_DOMAINS=pinklove.vn,www.pinklove.vn
ADMIN_DOMAINS=system.pinklove.vn
```

Nhieu admin domain:

```env
ADMIN_DOMAINS=system.pinklove.vn,office.pinklove.vn,internal.pinklove.vn
```

Env value la host, khong gom protocol.

Domain helper
-------------

Tao `web/src/lib/domains.ts` de parse va normalize:

```ts
PUBLIC_DOMAINS
ADMIN_DOMAINS
```

Yeu cau helper:
- Tach danh sach theo dau phay.
- Trim whitespace.
- Normalize lowercase.
- Ho tro host co port cho local dev.
- Cung cap ham kiem tra host thuoc admin/public domain.

Checklist trien khai
--------------------

1. Tao `web/src/lib/domains.ts`.
2. Cap nhat `web/src/proxy.ts` de rewrite theo host.
3. Chuyen public website routes vao `web/src/app/user-site`.
4. Chuyen customer routes vao `web/src/app/user-site/customer`.
5. Chuyen provider routes vao `web/src/app/user-site/provider`.
6. Chuyen admin routes vao `web/src/app/admin-site`.
7. Cap nhat `ROUTES.ADMIN`, `ROUTES.CUSTOMER`, `ROUTES.PROVIDER`.
8. Cap nhat navigation, breadcrumbs, permission rules, redirects, form actions va API response locations.
9. Cap nhat robots/sitemap/page path logic theo structure moi.
10. Chay typecheck/build.
11. Test local bang `localhost:3000` va `system.localhost:3000`.
