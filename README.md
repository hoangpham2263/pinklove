# PinkLove Next.js Project

Modern web application built with Next.js 15 (App Router), React 19, and PostgreSQL.

## Getting Started

1. Ensure Docker Desktop is running.
2. Run `./setup up` to build and start the environment in detached mode.
3. Access the web app at `http://localhost:3000` (or the port defined in `.env`).

## Documentation

All project documentation is located in the `@docs/` directory:

- [**Conventions**](./@docs/CONVENTIONS.md): Coding standards and project rules.
- [**Project Structure & Features**](./@docs/PROJECT_STRUCTURE_AND_FEATURES.md): Overview of modules and functionality.
- [**Database Schema**](./@docs/DATABASE_SCHEMA.md): Detailed description of the DB tables.
- [**Media Library**](./@docs/PROJECT_STRUCTURE_AND_FEATURES.md#7-media-library-standard-wordpress-like): How media is handled.

## Commands

- `./setup rebuild`: Full clean and rebuild.
- `./setup logs`: View real-time logs.
- `./setup down`: Stop all containers.
